Phone Setup Hub

Pair a new phone over WiFi · link Tailscale · live dashboard — all in the browser

1 Pair a brand-new phone (no USB)

On the phone: check so Wireless debugging is ON, then open "Pair device with pairing code" and keep it open.
Easiest way: plug the phone into this PC with USB debugging ON, press the green button — it arms 5555, finds the IP, saves it, and links Tailscale by itself.

2 Link the phone to Tailscale

Phone should already be signed into the same Tailscale account as this PC (tap ON in the Tailscale app).
